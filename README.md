
# Bella Vista Salon

## Project Description
Bella Vista Salon is a Flask-based appointment booking prototype developed for EGN475 Software Prototyping.

## Features
- Home page
- View salon services
- View individual service details
- Book an appointment
- Staff calendar
- View appointment history

## Technologies Used
- Python
- Flask
- HTML
- Jinja2
- GitHub

## How to Run
1. Create a virtual environment.
2. Install dependencies using:

   pip install -r requirements.txt

3. Start the Flask application:

   flask --app app run --debug

4. Open http://127.0.0.1:5000 in your browser.
